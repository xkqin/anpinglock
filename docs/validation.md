# 安屏 AnpingLock v1.1.0 验证

## 改名与兼容升级

项目的 UI、原生后台、命名空间、构建目标、代码目录、安装包和 GitHub 地址统一使用 AnpingLock。少量旧名称仅用于识别、停止旧后台和迁移设置；旧版发布说明及历史测量记录保留原名。

安装器保留原有升级标识，安装器、界面和原生后台首次启动均支持从旧数据目录迁移设置，使用新版内置助手停止新旧任务和界面。首次升级将旧设置复制到 `%LOCALAPPDATA%\AnpingLock`，保留手机地址、名称、语言和启用状态；已有新设置时不覆盖。不迁移旧的离开倒计时，避免改名升级后恢复过时的锁屏请求。新后台同时持有兼容互斥锁，阻止旧后台重复运行。

## 验证范围

- 31 项托管策略检查、8,583 次原生策略对照。
- 完整 Windows 构建、安装包生成、实际安装升级及自动恢复。
- 检查旧任务和进程移除、单个新原生后台、设置保留和安装显示名称。
- 本机资源采样，检查后台未加载 CLR。
- 中英文界面由实际 v1.1.0 程序导出，不使用概念效果图。

本地证据位于 `artifacts/build-1.1.0.log`、`artifacts/install-1.1.0.log`、`artifacts/upgrade-validation.json` 和 `artifacts/resources-1.1.0.json`。公开 Release 附不含设备信息的验证摘要。

Windows 动态锁保持原设置。本次未专门实施携手机离开、返回并实际触发锁屏的完整测试。[改名前 v1.0.2 的测量记录](archive/validation-awaylock-v1.0.2.md)。

## 本机检查结果（2026-11-11）

实际升级后检查通过：手机地址、名称、语言和启用状态保留；旧任务和旧进程已移除；只运行一个 AnpingLock.Agent 原生后台，界面未常驻；Windows 安装显示名称为“安屏 AnpingLock 版本 1.1.0”。Windows 动态锁保持启用。

v1.1.0 的约 30.26 秒资源采样包含 connected 和 active 状态：驻留内存 17.78 MiB（采样峰值 17.79 MiB），私有内存 3.45 MiB，累计 CPU 时间 46.875 毫秒，3 次写入、1019 字节有效载荷；未加载 CLR。数据随蓝牙状态和系统环境变化。

正式后台计划任务直接运行 AnpingLock.Agent.exe，未调用 PowerShell。开发目录中的 PowerShell 脚本仅用于手动构建和检查，不作为常驻任务安装。
